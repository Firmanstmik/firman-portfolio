# Firman Maulana — Portfolio

Premium personal portfolio with live production case studies.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Lenis smooth scroll

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Capture project screenshots

```bash
npm run capture
```

## Build

```bash
npm run build
npm run preview
```
